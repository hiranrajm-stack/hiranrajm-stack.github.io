Cookie Cats A/B Test — Gate Placement & Retention Analysis

Analyzed a real mobile-game A/B test of 90,189 players to determine whether delaying a progression gate improved or hurt player retention — with a statistically rigorous verdict and an AI-automated business memo.

SQLBigQueryPython statsmodelsPower BIGemini API
  • Queried and aggregated Day-1 and Day-7 retention rates across 44,700 control and 45,489 treatment players using BigQuery SQL
  • Ran a two-proportion z-test (z = 3.16, p = 0.0016) and a 95% confidence interval to separate statistical significance from practical business impact
  • Built an automation script using the Gemini API to generate the executive business memo directly from the statistical output — not manually written
Key Finding

Moving the gate to level 40 significantly decreased Day-7 retention (19.02% → 18.20%, 95% CI: 0.31–1.33pts) with no engagement upside — recommendation: keep the gate at level 30.

Google E-Commerce Funnel & Retention Analysis

Funnel and cohort retention analysis on 4.3M+ real e-commerce events across 8 weekly cohorts — paired with a business memo generated automatically via the Gemini API.

SQLBigQueryWindow Functions Power BIPythonGemini API
  • Built the full purchase funnel (view → add to cart → begin checkout → purchase) in BigQuery SQL on Google's public GA4 e-commerce dataset — 4.3M+ real anonymized events from the Google Merchandise Store
  • Used SQL window functions (DATE_TRUNC, DATE_DIFF, cohort self-join) to group users by their first-visit week and measure how many returned in the weeks after — the cohort retention analysis
  • Wrote a Python script that sends the finished findings to the Gemini API and generates the stakeholder business memo automatically — the analysis is mine, the write-up is script-generated from it
Key Finding

Only 1.5% of users who view a product ever purchase. Two separate leaks drive it: 85% drop off before adding to cart (a demand/merchandising problem) and 85% of checkout-starters never finish (a friction problem) — two different owners, two different fixes. Retention is just as steep: only 4% of new users return the week after their first visit, consistent across all 8 cohorts analyzed.
